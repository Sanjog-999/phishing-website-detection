# Phishing Website Detection Using Machine Learning

## 1. Project Overview

Phishing Website Detection Using Machine Learning is a machine learning-based project designed to identify potentially phishing and legitimate URLs. The system uses a Random Forest classifier to analyze prepared URL-related features and predict whether a website is phishing or legitimate.

The project includes a Flask-based web application that provides an interface for interacting with the detection system.

## 2. Objectives

- Detect potentially phishing websites using machine learning.
- Distinguish phishing URLs from legitimate URLs based on extracted features.
- Evaluate model performance using a separate test dataset.
- Provide a simple web interface for phishing detection.
- Explore the application of machine learning in cybersecurity.

## 3. Technologies Used

- **Programming Language:** Python
- **Machine Learning:** Scikit-learn
- **Data Processing:** Pandas, NumPy
- **Web Framework:** Flask
- **Model:** Random Forest Classifier
- **Dataset:** PhiUSIIL Phishing URL Dataset

## 4. Main Features

- Dataset preprocessing and feature preparation.
- Machine learning model training.
- Classification of phishing and legitimate examples.
- Model evaluation using held-out test data.
- Flask-based web application.
- Prediction results displayed through the application, subject to the implemented input and output functionality.

## 5. System Architecture

The system follows a machine learning-based workflow.

**Architecture Flow:**

PhiUSIIL Dataset  
↓

↓  
Feature Preparation and Extraction  
↓  
Random Forest Model Training  
↓  
Model Evaluation

### Architecture Components

**1. Dataset:** The PhiUSIIL Phishing URL Dataset is used as the data source for model development.

**2. Data Preprocessing:** The training script prepares the dataset and selects the required features for model training.

**3. Feature Preparation:** URL-related features are prepared in the format expected by the trained classifier.

**4. Model Training:** A Random Forest classifier is trained to distinguish between phishing and legitimate examples.

**5. Model Evaluation:** The trained model is evaluated using held-out test data to measure its classification performance.

**6. Web Application:** Flask provides the web application interface and connects the implemented prediction workflow to the trained model.

## 8. Dataset and Class Labels

The project uses the PhiUSIIL Phishing URL Dataset.

According to the current training script's class-label convention:

- `1` represents phishing.
- `0` represents legitimate.

The training output indicates that a balanced subset of 120,000 records was used for model development, with 60,000 examples from each class. The held-out test set contained 24,000 records.

## 12. Limitations
